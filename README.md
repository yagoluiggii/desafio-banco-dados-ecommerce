# desafio-banco-dados-ecommerce
# Refinamento do Projeto Conceitual de Banco de Dados - E-commerce

Este repositório contém o modelo refinado de um banco de dados para e-commerce.

## Refinamentos Implementados

1. **Cliente PF e PJ**: Implementada especialização exclusiva via tabela `Cliente` vinculada às tabelas `Pessoa_Fisica` e `Pessoa_Juridica`.
2. **Pagamentos**: Modelagem 1:N permitindo ao cliente cadastrar múltiplas formas de pagamento.
3. **Entrega**: Criada a entidade `Entrega` contendo status e código de rastreio para acompanhamento dos pedidos.
